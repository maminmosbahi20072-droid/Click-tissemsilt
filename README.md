# اضغط تيسمسيلت

واجهة لعبة ضغط عربية RTL بالأسود والذهبي، مبنية بـ React + Vite وSupabase.

## مهم قبل النشر
المشروع يحتوي على واجهة معاينة تعمل مباشرة دون إعدادات، لكن النقاط في وضع المعاينة تُحفظ على الجهاز نفسه فقط. لتصبح اللعبة مشتركة بين كل اللاعبين، اتبع الخطوات التالية.

## 1) أنشئ قاعدة البيانات
1. أنشئ مشروعًا جديدًا على https://supabase.com
2. افتح SQL Editor في المشروع.
3. الصق وشغّل محتوى `supabase/schema.sql`.
4. من Authentication > Sign In / Providers فعّل **Anonymous Sign-ins**.

## 2) اربط التطبيق
1. انسخ `.env.example` إلى ملف اسمه `.env` في جذر المشروع.
2. في Supabase > Project Settings > API انسخ Project URL والمفتاح publishable/anon إلى `.env`:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
3. ثبّت Node.js (إصدار حديث)، ثم شغّل:
   ```bash
   npm install
   npm run dev
   ```
4. للاختبار النهائي:
   ```bash
   npm run build
   ```

## 3) انشره على الإنترنت
- ارفع المشروع إلى مستودع GitHub.
- أنشئ مشروعًا على Vercel أو Netlify واربطه بالمستودع.
- أضف متغيري البيئة نفسيهما في إعدادات الاستضافة، ثم انشر المشروع.

## ملاحظات أمنية مهمة
- لا تضع `service_role` أو أي مفتاح سري في الواجهة.
- دخول الاسم وحده لا يثبت هوية صاحبه. هذا الإصدار يستخدم جلسة Supabase مجهولة؛ لاسترجاع الحساب من جهاز آخر أو حماية الاسم بشكل أقوى، أضف لاحقًا تسجيلًا برقم هاتف/بريد أو رمز استعادة.
- يجب إضافة حدّ سرعة حقيقي داخل قاعدة البيانات/دالة الخادم قبل فتح اللعبة على نطاق واسع؛ عدّل `add_click` لفرض rate limit باستخدام سجلّات ضغط مؤقتة أو Edge Function. لا تعتمد على واجهة المتصفح لمنع الغش.
- الاسم الفريد يمنع التكرار في قاعدة البيانات. لا يمكن ضمان هوية اللاعب بمجرد الاسم فقط.
